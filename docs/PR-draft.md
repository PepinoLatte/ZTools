## 描述（直接粘贴）

你好！我在使用 ZTools 时补了两个自己很需要的功能，实现已完成并通过测试，
希望能回馈上游。所有改动都以 `[ZT-Enhance]` 注释标记，全局搜索即可定位；
如果方向合适但实现细节你想调整，我非常乐意按你的意见修改。

### 功能一：新插件自动固定（AutoPin）

**动机**：插件市场装完插件后，需要手动搜索并固定到搜索面板；插件更新后
asar 文件名（含版本+哈希）变化，已固定的条目会因路径失效而消失。

**实现**：在 `writeInstalledPlugins`（插件注册表唯一写入入口）写入注册表后，
同步为"本次新出现的插件"补固定到 `pinned-commands` 与 `super-panel-pinned`，
写入时机早于面板的 `plugins-changed` 刷新事件，因此装完即可见，无需重启；
同时把两条固定列表中的旧 asar 路径修复为新路径；以覆盖前注册表为基准判断
"新插件"，手动取消固定的插件不会被自动加回。搜索面板条目带 pinyin-pro
拼音字段（pinyin / pinyinAbbr），与原生固定格式完全一致。

### 功能二：插件批量管理（通用设置页新卡片）

**动机**：跟随启动 / 关闭后自动销毁 / 自动分离窗口目前只能逐插件设置，
我希望能批量管理。

**实现**：通用设置页新增「插件批量管理」卡片，三个行为各自支持：

- 全局模式（对全部插件及未来新装插件生效，存于 `batch-plugin-manage` 文档，
  主进程在启动预加载 / 插件退出销毁 / 点击启动三处决策点实时读取）
- 精确模式（勾选具体插件，写入原生 `auto-start-plugin` /
  `out-kill-plugin` / `auto-detach-plugin` 列表，与既有单插件设置互通）
- 自动分离窗口默认开启（对标我个人"全部独立窗口"的使用习惯，可在卡片中关闭）

批量开关优先于单插件配置；关闭批量开关后回落到按插件配置，互不覆盖。
选择插件的弹窗带图标（复用 AdaptiveIcon）、描述、搜索过滤与市场详情跳转
（sessionStorage 交接给市场页的 openPendingPluginDetail 流程）。

### 测试情况

- `tsc --noEmit`（主进程）与 `vue-tsc --noEmit`（setting 插件）全部通过
- 实机验证：安装新插件后无需操作即出现在双击 Alt 面板；插件更新后固定不丢；
  三个批量开关实时生效（跟随启动按机制需重启）
- 指令缓存一致性：不触碰 `cached-commands`，全部走官方刷新链路

### 兼容性说明

- 未新增任何依赖（pinyin-pro / lmdb 为既有依赖）
- 存储仅新增 `ZTOOLS/batch-plugin-manage` 一个文档键
- 对 `internal-plugins` 打包方式零改动；asar 解包/重打包流程与官方一致
- `scripts/deploy-build.js` 是我本地"源码改完一键部署"的开发辅助脚本，
  如你认为不适合进主仓库，我可以移出 PR 或移到文档里
